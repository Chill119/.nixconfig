# DigiBank Wallet Platform Scaffold

Improved scaffold for wallet core, backend, and UI preview.

## Included

- `packages/wallet-core`: wallet creation and payment-request primitives
- `apps/backend`: zero-dependency Node HTTP API (`/health`, `/wallets`, `/payment-requests`)
- `apps/ui`: reusable wallet card rendering helpers and a static browser preview

## Preview UI

Open `apps/ui/preview.html` in a browser.

## Build

```bash
cd wallet-platform
npm install
npm run build
```
